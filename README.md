# Zazzle Store Builder

A custom WordPress plugin for integrating Zazzle product collections into WordPress websites. It retrieves product information through Zazzle RSS feeds and displays products using configurable layouts.

## Features

- Retrieves products from Zazzle collections via RSS feeds.
- Displays product images, titles and links to the Zazzle marketplace.
- Supports three display layouts:
  - **List:** Vertical product presentation.
  - **Side:** Horizontal scrolling product display.
  - **Grid:** Responsive product card layout.
- Uses configurable WordPress shortcodes.
- Includes a WordPress administration page with usage instructions.
- Supports multilingual interface text through Polylang.
- Provides custom CSS styling for product displays.

## Usage

Insert the shortcode into a WordPress page or post:

`[zazzle collection="COLLECTION_ID" layout="grid"]`

Available layouts:

- `list`
- `side`
- `grid`

Replace `COLLECTION_ID` with the ID of your Zazzle collection.

## Technical Details

- **Platform:** WordPress
- **Language:** PHP
- **Frontend:** HTML, CSS
- **JavaScript:** WordPress-compatible frontend
- **External Data:** Zazzle RSS feeds
- **Integration:** WordPress Shortcodes
- **Multilingual Support:** Polylang

## Project Context

Developed for Tamino Travel to integrate personalized Zazzle souvenirs into a WordPress-based tourism website.
